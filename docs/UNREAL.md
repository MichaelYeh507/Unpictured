# The Unreal Engine client

Unpictured's second phase runs on Unreal Engine 5 and C++. The web client (`web/`, `core/`) is
stopped and stays in the repo as the spec and reference: the world package, the test vectors in
`tests/`, the Python pipeline and every design decision carry over, and the viewer's dream shaders
are the reference for the HLSL port. This page is the setup and build guide for `unreal/`.

## What is in `unreal/`

- `Unpictured.uproject`: engine 5.7, one runtime module, the engine's default plugins with
  AndroidFileServer turned off (otherwise the editor writes a security token into `DefaultEngine.ini`).
- `Source/Unpictured/`: the module (`Unpictured.h`, `Unpictured.cpp`, log category `LogUnpictured`),
  `UnpicturedGameMode` (which pawn and player controller to spawn), `FreeFlyPlayerController` (the
  mouse stays free between drags) and `FreeFlyPawn` (the first-person camera and its controls).
  The pawn builds its Enhanced Input actions and key mappings in code, so there are no input assets.
- `Config/`: `DefaultEngine.ini` (start map, game mode, DirectX 12 with Shader Model 6, no static
  lighting), `DefaultInput.ini` (Enhanced Input classes, the mouse is captured only while a button is
  held, the legacy yaw and pitch scales are off), `DefaultGame.ini` (project name and id).
- `Content/Maps/Start.umap`: the first map, the engine's Basic level (floor, sun, sky, fog) plus
  four gray blocks and a player start at eye height. `Tools/make_start_map.py` made it; the command
  to remake it is in the script.
- `.gitignore`: `Binaries`, `Intermediate`, `Saved`, `DerivedDataCache`, `Build` and IDE files, all
  regenerated by a build or by the editor. `Build/` comes off the list if platform resources such as
  an icon are ever added there.

## Controls

Hold the left mouse button and drag to look. W and S move along the view, pitch included; A and D
sideways; E up and Q down; Shift flies five times faster. There is no collision yet (that is M3).
The numbers live on the pawn as editable settings: `Speed` 300 cm/s, `FastMultiplier` 5 and
`LookDegreesPerPixel` 0.11, which is the web viewer's feel (about 1,650 pixels for a half turn).

## Setup on Windows

1. Visual Studio 2022 Community 17.14 or later with the workloads "Game development with C++"
   (MSVC 14.44 and a Windows 11 SDK), "Desktop development with C++" and ".NET desktop development".
   Unreal 5.7 refuses compilers 14.44.35207 to 14.44.35210 (a compiler bug). It checks the version
   the compiler reports, not the toolset folder's name: with 17.14.39 the folder is still called
   `14.44.35207` but the compiler inside is 14.44.35228, which passes.
2. Unreal Engine 5.7.4 from the Epic Games Launcher: Unreal Engine tab, Library, the plus next to
   Engine Versions, pick 5.7, Options with Windows as the only platform, Install. It takes 26 GB at
   `C:\Program Files\Epic Games\UE_5.7`. The first launch runs the engine's prerequisites installer.
3. Memory: the editor takes about 2.5 GB and a build several more. On a 16 GB laptop close the
   browser and the launcher before building.

## Build from the command line

From the repo root:

```
"C:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\Build.bat" UnpicturedEditor Win64 Development -Project="%CD%\unreal\Unpictured.uproject" -WaitMutex
```

The first build takes a few minutes; later ones only rebuild what changed. "Unable to build while
Live Coding is active" means the editor, or its `LiveCodingConsole.exe`, is still running: close it.

Visual Studio project files are not committed (`*.sln` is ignored). Generate them with:

```
"C:\Program Files\Epic Games\UE_5.7\Engine\Build\BatchFiles\Build.bat" -projectfiles -project="%CD%\unreal\Unpictured.uproject" -game -rocket -progress
```

## Run

The editor:

```
"C:\Program Files\Epic Games\UE_5.7\Engine\Binaries\Win64\UnrealEditor.exe" "%CD%\unreal\Unpictured.uproject"
```

The game in its own window, without the editor:

```
"C:\Program Files\Epic Games\UE_5.7\Engine\Binaries\Win64\UnrealEditor.exe" "%CD%\unreal\Unpictured.uproject" -game -windowed -ResX=1280 -ResY=720
```

The first run compiles the engine's shaders for this project, which takes minutes; the result is
cached in `DerivedDataCache` and in the engine's shared cache.

## Checks

GitHub Actions cannot build `unreal/`: the engine is a 26 GB licensed install with no runner image,
so the Unreal part of each pull request is verified locally (a clean clone built and run on the
development machine, with the build log and screenshots in the PR), and the repo's web and pipeline
gates keep running in CI. From U2 the plan is a game core in plain C++ that CI builds and tests,
with the Unreal layer on top of it checked locally.
